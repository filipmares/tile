Tile is running

Tile has no main window — it lives in the menu bar. Hold the modifier below and press an arrow to place the focused window.

    Press the same arrow again to change the size. Every other action is in Shortcuts below, ready to bind to keys of your own.

    Development build

    This copy was built from a checkout, not installed from a release. It keeps its settings separately from an installed copy of Tile, and it never changes the system login item — “Launch Tile at login” is saved here but not applied.

    Updates

    Accessibility permission needed

    Tile needs macOS Accessibility permission to move other apps' windows. Until it is granted, its keyboard shortcuts do nothing.

    System Settings ▸ Privacy & Security ▸ Accessibility

    Fine-tune spacing and what happens when you repeat a shortcut.

    Repeating shortcuts

    Pressing the same shortcut again changes the size instead of repeating the move. The left and right arrows cycle half, then two thirds, then a third, then back to half. The cycle restarts when you run a different action, switch to another window, or move the window yourself.
