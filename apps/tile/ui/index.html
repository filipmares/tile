Welcome to Tile

Tile has no main window. It runs in the background, and its icon is in the menu bar.

Try it now

Click any window to focus it, then hold the modifier and press one of these.

    Press the same shortcut again

    Repeating a shortcut changes the size instead of repeating the move. The left and right arrows cycle half, then two thirds, then a third, then back to half. The cycle restarts when you run a different action, switch to another window, or move the window yourself.

    Moving between displays

    Throwing a window to another display keeps its slot where it can — a left third stays a left third. A window that is not in a recognisable slot keeps its relative place instead, measured against each display's own work area, so mixed-resolution setups behave.

    Everything else

    Tile has more window actions in total. The ones above are bound out of the box; the rest are waiting in Settings for keys of your own, next to window spacing, motion and startup.

    You can reopen this from the bottom of Settings.

    Development build

    This copy was built from a checkout, not installed from a release. It keeps its settings separately from an installed copy of Tile, and it never changes the system login item — “Launch Tile at login” is saved here but not applied.

    Updates

    Accessibility permission needed

    Tile needs macOS Accessibility permission to move other apps' windows. Until it is granted, its keyboard shortcuts do nothing.

    System Settings ▸ Privacy & Security ▸ Accessibility
